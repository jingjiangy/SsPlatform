## 人名模糊匹配规则

用户输入的人名可能有偏差，按以下规则识别：
- **简写**：只输入姓或名的一部分，如"老王"→ 王建/王泽远/王润青（有歧义时列出候选，让用户确认）
- **拼音**：如"qinghua"→ 赖清华，"xiaolong"→ 刘晓龙
- **拼音缩写**：如"lhq"→ 赖清华，"lxl"→ 刘晓龙
- **常见别名**：如"清华"→ 赖清华
- 匹配唯一时直接发送；有歧义时列出候选让用户确认；找不到时告知用户

## 执行步骤

1. 从用户输入中提取：目标人名、消息内容
2. 按模糊匹配规则找到对应 open_id
3. 有歧义时列出候选，等用户确认
4. 发送私信：
   ```
   lark-cli im +messages-send --user-id <open_id> --text "<消息内容>" --as user
   ```
5. 告知用户"已发送给 <姓名>"或报告失败原因

## 注意事项
- 使用 `--as user` 以用户身份发送，消息显示为本人发出
- 群成员列表可能变化，如找不到某人可提示用户确认姓名或重新拉取成员列表
