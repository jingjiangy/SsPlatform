# 业务概述

## 平台简介

SsPlatform 是一个人形机器人任务评测平台，用于管理世界模型视频素材、对机器人硬件执行结构化评测任务，并汇总打分数据供分析使用。

## 核心业务流程

```
世界模型素材（视频）
        ↓
  评测模板（步骤定义 + 评分标准）
        ↓
  评测任务（关联素材版本 + 机器人 + 评测员）
        ↓
  评测记录（视频录制 + 逐步打分）
        ↓
  统计与报告
```

## 功能模块

### 系统管理
- **角色管理** — 定义每个角色可访问的模块和操作权限
- **账号管理** — 创建账号并分配角色

### 世界模型素材库
- 上传并版本化管理世界模型视频片段
- 附加元数据（场景类型、难度等）
- 管理评测模板，定义素材对应的评测步骤和评分标准

### 评测任务
- 将素材版本与机器人关联，创建评测任务
- 评测员录制机器人执行任务的视频
- 按模板中定义的步骤逐项打分
- 查看单任务统计及跨任务汇总数据

### 设备管理
- **设备型号** — 硬件型号目录
- **机器人** — 关联设备型号的具体机器人实例

### 接口文档
- 内嵌 Swagger UI，支持在线浏览和调试 REST API

## 角色说明

| 角色 | 编码 | 典型职责 |
|------|------|---------|
| 管理员 | `admin` | 全权限——用户/角色管理、所有模块 |
| 评测员 | `evaluator` | 执行评测、管理素材和模板、查看设备信息 |
| 研发 | `rd` | 素材、评测、设备管理的写权限 |
| 采集员 | `collector` | 素材和设备信息的只读权限 |

## 默认账号

首次启动空库时，系统自动初始化一个管理员账号：

| 字段 | 值 |
|------|----|
| 用户名 | `admin` |
| 密码 | `admin123` |

首次登录后请立即修改密码。
